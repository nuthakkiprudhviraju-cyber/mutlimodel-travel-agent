## 1. Authentication

All secured endpoints require the standard Bearer token header:
```http
Authorization: Bearer <access_token>
```
Tokens are generated by `POST /api/v1/auth/login` and are valid for **30 minutes**.

---

## 2. API Endpoints Summary

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| `POST` | `/auth/register` | Register a new user | No |
| `POST` | `/auth/login` | Authenticate & retrieve 30-min JWT | No |
| `GET` | `/auth/me` | Fetch active user profile | Yes |
| `POST` | `/trips/parse-request` | Parse free-form prompt using Gemini AI | Yes |
| `POST` | `/trips/plan` | Execute graph timetable planning | Yes |
| `GET` | `/trips` | List all trips for current user | Yes |
| `GET` | `/trips/{trip_id}` | Retrieve single trip by ID | Yes |
| `GET` | `/trips/{trip_id}/itineraries` | Retrieve all itineraries for a trip | Yes |
| `GET` | `/trips/osrm-route` | Calculate road distance & coordinates via OSRM | Yes |
| `GET` | `/trips/places-along-corridor` | Query Overpass for attractions, dining & hospitals | Yes |
| `POST` | `/bookings` | Create a saved trip in `PENDING_APPROVAL` status | Yes |
| `GET` | `/bookings` | List all saved & confirmed trips | Yes |
| `GET` | `/bookings/{booking_id}` | Retrieve a booking by ID | Yes |
| `PATCH` | `/bookings/{booking_id}` | Update unconfirmed trip (locks if confirmed) | Yes |
| `POST` | `/bookings/{booking_id}/approve` | Confirm trip & lock reservation (`ROAM-SIM-XXXX`) | Yes |
| `POST` | `/bookings/{booking_id}/cancel` | Cancel an existing booking | Yes |
| `DELETE`| `/bookings/{booking_id}` | Permanently delete a saved trip | Yes |
| `POST` | `/disruptions/simulate` | Simulate transit delay & compute alternatives | Yes |
| `GET` | `/disruptions` | List active disruptions | Yes |
| `GET` | `/notifications` | List user activity notifications | Yes |
| `PATCH` | `/notifications/{id}/read` | Mark a notification as read | Yes |
| `POST` | `/demo/reset` | Reset database to seed state (ADMIN only) | Yes (Admin) |

### 3.2 Trips & Corridor Routing

#### `POST /trips/parse-request`
- **Description:** Invokes Google Gemini AI (`gemini-3.8-flash`) to parse natural language queries into structured parameters.
```json
// Request
{
  "prompt": "Book a bus from Chennai to Hyderabad on 2026-10-25 arriving before 8:00 AM with sleeper seat",
  "language": "en"
}

// Response (200 OK)
{
  "origin": "Chennai",
  "destination": "Hyderabad",
  "departure_date": "2026-10-25",
  "arrival_deadline": "08:00",
  "max_budget": null,
  "passenger_count": 1,
  "seating_preference": "SLEEPER",
  "preferred_modes": ["BUS"],
  "selected_places": [],
  "luggage_needed": false,
  "accessibility_needs": false
}
```

#### `POST /trips/plan`
```json
// Request
{
  "title": "Chennai to Hyderabad Corridor",
  "constraints": {
    "origin": "Chennai",
    "destination": "Hyderabad",
    "departure_date": "2026-10-25",
    "arrival_deadline": "08:00",
    "max_budget": 2000.0,
    "passenger_count": 1,
    "seating_preference": "SLEEPER",
    "preferred_modes": ["BUS", "TRAIN"]
  }
}
```

#### `GET /trips/osrm-route`
- **Query Parameters:** `origin=Chennai&destination=Hyderabad&mode=driving`

### 3.3 Bookings & Trip Details

#### `POST /bookings`
```json
// Request
{
  "itinerary_id": "itin-uuid",
  "passenger_name": "Naveen Traveller",
  "passenger_count": 1,
  "idempotency_key": "trip-itin-uuid-1791664",
  "rapido_pickup_requested": true,
  "rapido_pickup_fare": 75.0,
  "rapido_drop_requested": true,
  "rapido_drop_fare": 95.0
}

// Response (200 OK)
{
  "id": "booking-uuid",
  "trip_id": null,
  "itinerary_id": "itin-uuid",
  "status": "PENDING_APPROVAL",
  "total_amount": 1520.0,
  "passenger_name": "Naveen Traveller",
  "passenger_count": 1,
  "rapido_pickup_requested": true,
  "rapido_pickup_fare": 75.0,
  "rapido_drop_requested": true,
  "rapido_drop_fare": 95.0,
  "approval_decision": null,
  "confirmation_reference": null,
  "is_simulated": true,
  "created_at": "2026-10-11T01:45:00Z"
}
```

#### `PATCH /bookings/{booking_id}`
- **Note:** If booking is already `CONFIRMED_SIMULATED`, returns `HTTP 400 Bad Request`.
```json
// Request
{
  "itinerary_id": "alternate-itin-uuid",
  "passenger_name": "Naveen Traveller",
  "passenger_count": 2,
  "rapido_pickup_requested": true,
  "rapido_drop_requested": false
}
```

#### `POST /bookings/{booking_id}/approve`
- **Description:** Confirms trip, generates `ROAM-SIM-XXXX` reference, and permanently locks the booking.
```json
// Request
{
  "decision": "APPROVE"
}

// Response (200 OK)
{
  "id": "booking-uuid",
  "status": "CONFIRMED_SIMULATED",
  "approval_decision": "APPROVED",
  "confirmation_reference": "ROAM-SIM-8FA1C2B0",
  "is_simulated": true
}
```

#### `DELETE /bookings/{booking_id}`
```json
// Response (200 OK)
{
  "message": "Booking deleted successfully",
  "id": "booking-uuid"
}
```
